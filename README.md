# Employee Attrition Prediction using Decision Tree and Random Forest

## Objective

To predict employee attrition using Decision Tree and Random Forest Classification models and compare their performance.

## Dataset

https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Methodology

1. Loaded the dataset.
2. Checked for missing values.
3. Removed unnecessary columns.
4. Encoded categorical variables.
5. Split the data into training and testing sets.
6. Trained a Decision Tree model.
7. Trained a Random Forest model.
8. Evaluated both models using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
9. Compared the models and plotted Feature Importance.

## Results

The Random Forest model achieved better performance than the Decision Tree model in terms of Accuracy, Precision, Recall, and F1-Score.

## Model Comparison

Random Forest outperformed Decision Tree because it combines multiple trees, reducing overfitting and improving prediction accuracy.

## Conclusion

Random Forest is more accurate and reliable for employee attrition prediction, while Decision Trees are easier to understand but more prone to overfitting.
